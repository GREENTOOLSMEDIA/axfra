AXFRA LIGHTING 360 / Demostración

Cuatro focos, control independiente

Una configuración de iluminación modular aplicable a distintos escenarios. Cada foco conserva su posición, altura, intensidad y color sin alterar la identidad ni el fondo. Los valores iniciales y los metadatos corresponden al JSON del set de estudio. Ajusta los controles y observa cómo cambia el esquema y se actualiza el JSON para copiarlo o descargarlo. El dibujo es orientativo, no una simulación fotográfica.

Visualización aproximada de ubicación y color; no representa una fotografía ni un cálculo físico de la luz.

Independencia de variables

El set documentado por ALARSI para AXFRA inicia con los focos izquierdo y derecho apagados; frontal y posterior encendidos. El JSON completo conserva los metadatos de marca y se actualiza al modificar los controles.

JSON de iluminación · se actualiza con los controles


Los controles modifican en vivo el JSON que puedes copiar o descargar. «Clean / Layered» cambia solo el dibujo del esquema y no altera el JSON. «Restablecer» devuelve los valores originales de la fotografía de referencia. El JSON incluye identificador, autoría AXFRA / ALARSI y los parámetros de iluminación del set.
