AXFRA

Axion Frame Tools es el laboratorio de cuadro. No publica una foto suelta: arma un sistema para que un personaje vuelva a ser el mismo en el siguiente frame.

Aquí se prueba lo que una imagen no puede mentir. La identidad. La pose. La luz. El vestuario. El escenario. El paso de la foto al movimiento. Cada pieza tiene un id porque un frame sin nombre no se puede repetir, corregir ni comparar.

El elenco no es un desfile. Amina, Hana, Indira, Paulina, Viktoria, Mira, Mara y Dotsy son cuerpos con continuidad: misma cara, misma medida, otra orden. El prompt es la herramienta. La foto es la prueba.

AXFRA cuelga de Paulina Dots y trabaja aparte. El archivo narrativo se queda en el universo. Acá se queda el método.
