La imagen comienza antes del primer píxel.

AXFRA — Axion Frame Tools es un sistema de investigación, composición y producción visual con inteligencia artificial mediante prompts JSON estructurados y componentes reutilizables.

Permite dirigir imágenes, estudiar la consistencia de personajes y especificar poses, vestuario, cámara, iluminación y escenarios para proyectos editoriales y audiovisuales.

AXFRA no es un motor de generación de imágenes. Es un sistema para trabajar con motores externos; la fidelidad depende de cómo interpretan las instrucciones.

06 / Metodología

Del lenguaje a la estructura: cómo construir prompts JSON.

Una instrucción puede producir una imagen interesante. Pero cuando buscamos un resultado específico, cada ambigüedad importa. AXFRA estudia esas ambigüedades y desarrolla formas de describirlas con mayor precisión.

01 / OBSERVAR

Identificar el problema ↗

Examinar qué parte de una descripción admite interpretaciones diferentes: un material, un corte, una posición, una escala o una relación entre objetos.

02 / CLASIFICAR

Definir los componentes ↗

Separar estructuras y propiedades. Distinguir aquello que define una pieza de lo que puede variar: forma, material, color, transparencia o proporciones.

03 / ESTRUCTURAR

Escribir instrucciones ↗

Organizar descripciones en catálogos, identificadores, parámetros, reglas y estructuras JSON que faciliten la reutilización y la comparación.

04 / PROBAR

Contrastar con imágenes ↗

Aplicar las instrucciones en motores de generación visual y observar cómo se traducen las especificaciones en resultados concretos.

05 / AJUSTAR

Reducir ambigüedades ↗

Revisar las instrucciones cuando una prenda, una pose, un objeto o una composición no responde a lo solicitado.

06 / REUTILIZAR

Construir variaciones ↗

Modificar componentes específicos sin tener que redefinir toda la escena: cambiar el vestuario, conservar una identidad o sustituir un escenario.

La imagen muestra el resultado. AXFRA documenta las decisiones que lo hicieron posible.

09 / Sobre AXFRA

Investigación, composición y desarrollo tecnológico.

AXFRA reúne experimentos, instrucciones y especificaciones desarrollados a partir de problemas concretos de generación visual. La investigación se traduce en módulos reutilizables, herramientas propias y proyectos editoriales y audiovisuales.

El objetivo no es imponer una estética única. Es construir un sistema que permita describir, combinar y modificar los elementos de una imagen con mayor precisión. La fidelidad final depende del motor generativo y de su interpretación de las instrucciones. AXFRA es un proyecto desarrollado por ALARSI.
