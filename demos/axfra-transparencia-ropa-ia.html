03 / Cómo funciona

La transparencia no es un botón.

En esta prueba no se utilizó un único adjetivo como «transparente». Se antepusieron cuatro instrucciones complementarias al JSON de vestuario. Su combinación orienta al generador hacia una apariencia de tejido más abierto y transmisivo.

opacity: 0.1

Opacidad

Solicita una cobertura visual muy baja: se busca que aquello situado bajo la tela resulte más visible.

light_transmission: 0.9

Transmisión de luz

Solicita que una fracción elevada de la luz atraviese el tejido, contribuyendo a su apariencia translúcida.

fiber_density: 0.05

Densidad de fibra

Describe una trama visualmente muy poco densa. Ayuda a comunicar finura y menor cobertura del tejido.

transparency: 1

Transparencia solicitada

Refuerza la intención global del efecto. El valor no debe interpretarse como una medición física calibrada del motor.

La clave es la combinación. Estos nombres y valores son instrucciones semánticas para el modelo generativo, no controles físicos normalizados. Las imágenes muestran una respuesta útil a este conjunto, pero no aíslan el efecto de cada variable.

05 / Preguntas frecuentes

Transparencia de ropa con inteligencia artificial: dudas habituales

¿Cómo controlar la transparencia de la ropa generada con IA?

En esta prueba de AXFRA se mantuvo una camisa roja de lino como base y se antepusieron cuatro instrucciones: opacity, light_transmission, fiber_density y transparency. Las imágenes muestran un cambio perceptible, pero no garantizan resultados idénticos en todos los modelos.

¿Qué hace opacity en un prompt de imagen?

Es una indicación de cobertura visual: los valores bajos buscan que se perciba más de lo situado debajo del material. En un generador de imágenes es una instrucción semántica, no una simulación física garantizada.

¿Es necesario modificar el JSON de la prenda?

No. El objetivo de este experimento es conservar el JSON de vestuario y anteponer instrucciones de comportamiento óptico. El JSON original se muestra con una corrección exclusivamente sintáctica: tue se normalizó a true.

06 / Conclusión

Una solución modular para un problema visual concreto.

En este ensayo, anteponer cuatro parámetros al JSON de una prenda produjo una diferencia clara de apariencia óptica. No hizo falta crear otra definición de camisa: la estructura de vestuario pudo reutilizarse.

La prueba no demuestra que Grok interprete cada valor de manera independiente ni garantiza idénticos resultados con otros materiales. Sí ofrece un procedimiento documentado, visual y fácil de experimentar.
