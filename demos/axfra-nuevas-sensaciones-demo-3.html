01 / Fundamentos

Qué resuelve el enfoque modular.

El problema no es generar una imagen llamativa. Es mantener identidad y control cuando se abren varias variables al mismo tiempo: múltiples personajes, material de alto specular, espejos que multiplican reflejos, coreografía larga y objetos (instrumentos) que deben permanecer reconocibles.

En producción tradicional esta combinación es casi prohibitiva: ocho modelos, sala de espejos real, trajes metálicos que rebotan luz de forma incontrolable, instrumentos de nivel y el riesgo de que un solo reflejo o un color mal controlado rompa la continuidad. Aquí el sistema cita módulos ya validados y solo parametriza lo que cambia.

02 / La secuencia

De la sala de espejos al escenario.

La secuencia comienza en la sala de espejos (base AXFRA_env_vip_elevator con ajustes de luz). Las identidades aparecen con el mismo corte metálico. Luego se unen como banda: bajo, guitarra, batería y voz. El video cierra en escenario.

La coreografía final usa 37 pasos discretos. El material, los instrumentos y el entorno se mantienen como módulos citados. Solo se abren las variables de color, pose y expresión.

03 / Serie AXION FRAME 69

Un wardrobe. Variaciones controladas.

El mismo módulo de polera vintage (tank AXION FRAME 69 + short + cinturón) parametrizado en color y transparencia. La identidad, el entorno de club con neones y la estructura del gráfico se mantienen fijos.

04 / Módulos citados

Bloques reutilizados.

El video y la serie de poleras se construyen citando componentes existentes: entorno VIP Elevator, wardrobe metálico o AXION FRAME 69, coreografía de 37 pasos, instrumentos y finish_level. Se abren solo las variables necesarias.

Entorno base

AXFRA_env_vip_elevator

Sala de espejos infinito, chrome ahumado, mármol negro. Usado como punto de partida con ajustes menores de luz.

{
  "id": "AXFRA_env_vip_elevator",
  "background": "mirrored infinity walls, smoked chrome panels, glossy black marble floor",
  "lighting": "high-contrast nightclub light, subtle red-blue LED ambience"
}
Coreografía

AXFRA_motion_elegant_dance_37_step_sequence

37 pasos discretos. Define solo el movimiento. Identidad, vestuario y entorno quedan fuera del módulo.

{
  "id": "AXFRA_motion_elegant_dance_37_step_sequence",
  "style": "Elegant, fluid, controlled and sensual",
  "sequence": [ /* 37 steps */ ]
}
Wardrobe parametrizado

AXFRA_wardrobe_look_vintage_axion_frame_69

Colores, transparencia y gráfico como variables. El corte y la estructura del 69 se mantienen.

{
  "parameters": {
    "character_color": "faded off-apple green",
    "transparency": "50%"
  },
  "identity_lock": true
}
05 / Continuidad

La identidad permanece. Las variables se abren.

El sistema no busca validación de habilidad. Entrega un método para que una IA pueda componer con menos deriva: cita módulos validados, parametriza lo que cambia y mantiene el control de identidad, proporciones y continuidad incluso cuando se multiplican reflejos, colores y personajes.

Los módulos están en la librería de AXFRA. El método queda abierto porque el sistema sigue mejorando.

Demostración visual de ficción. Los módulos son instrucciones de composición, no garantía de reproducción idéntica en todos los motores.
