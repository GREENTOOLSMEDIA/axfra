Observar

Examinar qué parte de una descripción admite interpretaciones diferentes: un material, un corte, una posición, una escala o una relación entre objetos.

Identificar el problema

La observación comienza con una imagen o un resultado que no responde exactamente a la intención visual. Se identifica qué elemento presenta ambigüedad y qué información falta para describirlo con precisión.

Objetivo de esta etapa

Delimitar el problema visual antes de modificar instrucciones.

Ejemplo de aplicación

Por ejemplo, si una prenda no conserva su corte, se registra si la diferencia está en la silueta, el tejido, el ajuste o la relación con el cuerpo.

La metodología organiza el análisis visual; no reemplaza la evaluación de resultados generados.
