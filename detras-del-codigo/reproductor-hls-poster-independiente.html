Streaming HLS con póster independiente en HTML5.

Cómo resolvimos en AXFRA Motion un detalle aparentemente pequeño, pero importante para la experiencia visual: mantener un póster visible y controlado de forma independiente mientras el streaming HLS se prepara, evitando que desaparezca prematuramente al inicializar el video.

Ver AXFRA Motion ↗ Volver al índice

El problema

El video principal de AXFRA Motion usa una fuente HLS externa. La reproducción funcionaba, pero el comportamiento visual del póster no era consistente: al cargarse ciertos datos del video, la imagen de portada desaparecía antes de que el usuario percibiera el inicio real de la reproducción.

Qué queríamos lograr

  • Mostrar un póster claro y controlado desde AXFRA.
  • Mantener ese póster visible hasta que el video comenzara efectivamente.
  • Conservar los controles nativos del elemento <video>.
  • No romper la implementación HLS que ya funcionaba.
  • Evitar dependencias pesadas o interfaces artificiales.

Contexto técnico

La página está construida con HTML, CSS y JavaScript sobre GitHub Pages. El streaming proviene de una fuente externa HLS, y el comportamiento del reproductor debía seguir siendo estable tanto a nivel visual como funcional.

La solución

Separar póster y reproductor

En lugar de depender únicamente del atributo nativo poster del video, incorporamos una capa visual independiente: un botón superpuesto con la imagen de portada. Esa capa actúa como póster persistente y desaparece solo cuando el evento playing confirma que la reproducción ya comenzó.

Ventajas del enfoque

  • Control visual total del póster.
  • Mejor percepción de continuidad para el usuario.
  • Separación clara entre presentación y reproducción.
  • Posibilidad de reutilizar el patrón en otros proyectos.

Estructura HTML

HTML · Contenedor del video y póster independiente
<div class="axfra-video-stage">
  <video id="axfra-luz-camara"
         controls
         playsinline
         preload="none"
         poster="/motion/axfra_motion_luz_camara_indira_maria_poster.jpg"
         aria-label="Demostración de AXFRA Motion — Luz, Cámara, AXFRA">
  </video>

  <button class="axfra-video-poster"
          id="axfra-luz-camara-poster"
          type="button"
          aria-label="Reproducir Luz, Cámara, AXFRA">

    <img src="/motion/axfra_motion_luz_camara_indira_maria_poster.jpg"
         alt="Indira y M.A.R.I.A. abrazadas, formando un encuadre cinematográfico con sus manos.">

    <span class="axfra-video-play" aria-hidden="true">▶</span>
  </button>
</div>

Lógica JavaScript

JavaScript · Control del póster independiente
const poster = document.getElementById('axfra-luz-camara-poster');

if (poster) {

  poster.addEventListener('click', () => {
    video.play().catch(error => {
      console.warn('AXFRA Video:', error);
      poster.classList.remove('is-hidden');
    });
  });

  video.addEventListener('playing', () => {
    poster.classList.add('is-hidden');
    video.classList.add('playing');
  });

  video.addEventListener('ended', () => {
    poster.classList.remove('is-hidden');
    video.classList.remove('playing');
  });

  video.addEventListener('error', () => {
    poster.classList.remove('is-hidden');
    video.classList.remove('playing');
  });

}

Qué aprendimos

La experiencia visual también es arquitectura

El problema no era solamente “hacer que el video funcione”. También importaba cómo aparece, cómo espera y cómo se siente para el usuario. Resolver la capa visual fue tan importante como resolver el streaming.

Una solución pequeña puede ser reutilizable

Este patrón puede reutilizarse en otros contextos: páginas estáticas, demos audiovisuales, portfolios o sitios que dependan de fuentes HLS externas y necesiten una portada controlada con precisión.
